# منصة صانع الرجال | كُن الأَفْضَل

نسخة الدخول الحر والمباشر لرفعها على GitHub Pages:
1. `index.html`: الموقع الكامل لمنصة صانع الرجال (دخول مباشر وحر بدون بوابة دفع، تسجيل حساب بالبريد الإلكتروني والطول والوزن والهدف أو تصفح فوري، مشهد ترحيب 3D Motion Graphics، جداول التدريب PPL و Arnold Split، الأنظمة الغذائية المخصصة، جدول الأنشطة الأسبوعي، وخانة الدعم 01273568689).
2. `README.md`: ملف تعريف المستودع.

## خطوات النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على GitHub.
2. ارفع ملف `index.html` وملف `README.md` إلى الفرع `main`.
3. من **Settings -> Pages** اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
